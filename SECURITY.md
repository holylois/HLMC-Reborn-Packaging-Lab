# Reporting a security issue

Send suspected launcher, pack or account-recovery vulnerabilities privately to hello@holylois.com. Include the
affected version and steps using generated test data. Never attach passwords, recovery codes, tokens, player
account files or private backups. Public GitHub issues and community chat are unsuitable for sensitive reports.

The operator will review the report and coordinate a fix. This project does not offer a paid bounty or promise
a response deadline. For ordinary installation or gameplay problems, use https://holylois.com/support.
